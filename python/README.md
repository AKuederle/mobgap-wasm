# Browser dataset operations

`mobgap_demo_api.py` exposes two stateless operations. `load_index(path, metadata_path, configuration)` constructs a native mobgap dataset and returns its index rows. Each row contains a deterministic ID, a label and the actual index values as strings. `process(path, metadata_path, configuration, selected_rows, preset)` reconstructs the dataset, matches those index values and emits `__MOBGAP_EVENT__` JSON lines for running, complete and error events. The module retains no dataset or generator between calls and clears native dataset RAM caches when each operation ends. Small native header metadata memoization remains available.

MAT files use `GenericMobilisedDataset`, with an optional separate `infoForAlgo.mat`. The dataset converts companion heights from centimetres to metres. Manual participant and sensor heights override companion values. Effective heights must be finite and positive, and sensor height must not exceed participant height. Companion measurements are checked when the index is loaded. Cohort and measurement condition come from configuration. CWA uses `AX6Dataset` with explicit synchronization timezone and manual participant measurements. Automatic splitting chooses calendar days for recordings longer than 24 hours, otherwise the whole file. Explicit `days` and `file` choices preserve their native dataset semantics, including daylight-saving calendar boundaries.

Healthy and Impaired run their full named pipelines. Auto uses `MobilisedPipelineUniversal` with both pipelines and reports the chosen preset. Each child pipeline uses `retain_intermediate_results=False`. Results include all eight tables and counts. Scientific warnings go to stderr and the browser console. Ordinary row failures emit errors and processing continues. Memory errors, including allocation failures wrapped by scientific transformers, propagate to the runtime; results already emitted remain available. Cancellation is handled by replacing the browser worker.

Verify syntax with `python -m py_compile python/mobgap_demo_api.py`. Native smoke checks require a compatible mobgap environment. The browser runtime passes mounted file paths directly to these operations; decoded sensor frames and scientific pipeline allocations still require memory.
